Micro:bit og naturfag

Én økt à 90 minutter. Dere blir kjent med Microsoft MakeCode, lager tekst og symboler, utforsker knappene, sender meldinger – og tester hva som påvirker signalstyrken.

  • Varighet: 90 min
  • Gruppe: 2–3 elever
  • Verktøy: MakeCode (blokk) + Python

Læringsmål

  1. Finne fram i Microsoft MakeCode og laste ned program til micro:bit
  2. Vise tekst og symboler på skjermen
  3. Bruke knapp A og B til å styre programmet
  4. Sende og motta meldinger med radio (giver og mottaker)
  5. Undersøke hva som påvirker signalstyrken (elektromagnetiske bølger)

Del 1 – Bli kjent med Microsoft MakeCode (15 min)

Oppstart
  1. Gå til makecode.microbit.org
  2. Velg Nytt prosjekt og gi det et navn (f.eks. Oekt1)
  3. Se på arbeidsområdet:
    • Blokker til venstre
    • Simulator i midten
    • Kodeflate til høyre
  4. Test i simulatoren først – deretter Last ned og dra .hex-fila til micro:bit

Sjekkliste

  • Jeg har åpnet et nytt prosjekt
  • Jeg ser simulatoren reagere når jeg tester
  • Jeg har lastet ned minst ett program til den fysiske micro:biten

Tips: Bytt mellom Blokker og Python øverst i MakeCode for å se samme program på to måter.

Del 2 – Lag en tekst og et symbol (15 min)

Oppgave 2a – Vis en tekst

Få micro:bit til å vise en tekst når den starter, f.eks. navnet ditt eller «Hei».

Blokk

ved start
    → vis streng "Hei"

Python

from microbit import *

display.scroll("Hei")

Oppgave 2b – Lag et symbol

Vis et innebygd ikon (hjerte, smilefjes, …) eller tegn ditt eget mønster på 5×5-skjermen.

Blokk

ved start
    → vis streng "Hei"
    → pause (ms) 1000
    → vis ikon (hjerte)

Eget symbol: bruk vis lysdioder og tenn de lampene du vil.

Python

from microbit import *

display.scroll("Hei")
sleep(1000)
display.show(Image.HEART)

# Eller eget mønster (9 = full lysstyrke):
# mitt_symbol = Image("09090:99999:99999:09990:00900")
# display.show(mitt_symbol)
Naturfag

LED-skjermen lyser fordi elektrisk energi blir til lysenergi. Hvert «punkt» er en liten diode.

Del 3 – Utforsk knapp A og B (15 min)

Programmer slik at:

HandlingResultat
Trykk AViser en tekst (f.eks. «A») eller et tall
Trykk BViser et symbol (f.eks. smilefjes)
Trykk A+B (valgfritt)Nullstiller skjermen / viser noe tredje

Blokk

når knapp A trykkes
    → vis streng "A"

når knapp B trykkes
    → vis ikon (glad)

når knapper A+B trykkes
    → tøm skjerm

Python

from microbit import *

while True:
    if button_a.was_pressed():
        display.scroll("A")
    if button_b.was_pressed():
        display.show(Image.HAPPY)
    if button_a.is_pressed() and button_b.is_pressed():
        display.clear()
Utforsk videre
  • Kan du få A til å vise et tall som øker hver gang du trykker?
  • Hva skjer om du bruker «når knappen A er trykket» (kontinuerlig) i stedet for «når knapp A trykkes»?

Del 4 – Giver og mottaker: send beskjed (25 min)

Én micro:bit er giver (sender), den andre er mottaker.

Viktig: Begge må bruke samme radiogruppe (f.eks. gruppenummeret deres). Ellers snakker dere med feil gruppe.

Oppgave 4a – Send en kort beskjed

  • Giver: Trykk A for å sende teksten HEI
  • Mottaker: Vis det som mottas på skjermen

Blokk – giver

ved start
    → radio sett gruppe 3          ← bytt til deres gruppenummer

når knapp A trykkes
    → radio send streng "HEI"
    → vis ikon (ja)

Blokk – mottaker

ved start
    → radio sett gruppe 3

på radio mottatt streng
    → vis streng (mottatt streng)

Python – giver

from microbit import *
import radio

radio.on()
radio.config(group=3)  # bytt til deres gruppenummer

while True:
    if button_a.was_pressed():
        radio.send("HEI")
        display.show(Image.YES)
        sleep(400)
        display.clear()

Python – mottaker

from microbit import *
import radio

radio.on()
radio.config(group=3)

while True:
    msg = radio.receive()
    if msg:
        display.scroll(msg)

Oppgave 4b – Toveis prat

Programmer begge slik at A sender «HEI» og B sender «OK».

Blokk (samme program på begge)

ved start
    → radio sett gruppe 3

når knapp A trykkes
    → radio send streng "HEI"

når knapp B trykkes
    → radio send streng "OK"

på radio mottatt streng
    → vis streng (mottatt streng)

Python (samme program på begge)

from microbit import *
import radio

radio.on()
radio.config(group=3)

while True:
    if button_a.was_pressed():
        radio.send("HEI")
    if button_b.was_pressed():
        radio.send("OK")

    msg = radio.receive()
    if msg:
        display.scroll(msg)
Naturfag

Radioen bruker elektromagnetiske bølger (2,4 GHz) – samme type som Wi‑Fi og Bluetooth. Usynlige, men de bærer informasjon.

Del 5 – Signalstyrke: hva påvirker? (20 min)

Test systematisk hva som påvirker hvor godt signalet kommer fram.

Oppsett

  1. Én giver og én mottaker
  2. Giver sender når du trykker A
  3. Mottaker viser signalstyrke
  4. Noter i tabellen under

Blokk – giver

ved start
    → radio sett gruppe 3
    → radio sett sendeeffekt 6     ← maks er ofte 7

når knapp A trykkes
    → radio send streng "PING"
    → vis ikon (diamant)

Blokk – mottaker

ved start
    → radio sett gruppe 3

på radio mottatt streng
    → vis tall (radio signalstyrke)

Blokken «radio signalstyrke» finnes under Radio (avansert). Tallene er typisk negative (f.eks. −42). Nærmere null = sterkere signal (−30 er sterkere enn −80). Signalstyrke er enklest i MakeCode – bruk blokk til dette forsøket.

Python – giver

from microbit import *
import radio

radio.on()
radio.config(group=3, power=6)  # power 0–7

while True:
    if button_a.was_pressed():
        radio.send("PING")
        display.show(Image.DIAMOND)
        sleep(300)
        display.clear()

Forsøk – fyll inn

Hold giveren i ro. Endre én ting om gangen.

Test Hva gjør dere? Signalstyrke Kom melding fram?
11 m, fri sikt
25 m avstand
3Bak vegg / dør
4Person mellom
5Lavere sendeeffekt (f.eks. 1)
6Valgfritt: metall / vann mellom
Spørsmål til naturfag
  1. Hva skjedde med signalstyrken når avstanden økte? Hvorfor?
  2. Hvilket hinder reduserte signalet mest?
  3. Elektromagnetiske bølger dempes av materialer og avstand. Nevn én likhet med lys eller lyd.
Kort forklaring
  • Avstand: Energien fordeles over større område → svakere signal.
  • Hindre: Vegger, kropp og metall kan absorbere eller reflektere bølger.
  • Sendeeffekt: Lavere effekt = mindre energi = kortere rekkevidde.

Innlevering

  1. Skjermbilde eller kort beskrivelse av giver- og mottaker-programmet
  2. Ferdig tabell fra signalstyrke-forsøket
  3. Svar på de tre naturfagspørsmålene

Refleksjon (individuelt, 2–3 setninger)
