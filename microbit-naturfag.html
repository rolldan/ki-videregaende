Micro:bit og naturfag

Én økt à 90 minutter. Dere har allerede programmert trådløs kommunikasjon. Nå bruker dere sensorer til å samle data og forklare dem med naturfag.

  • Varighet: 90 min
  • Gruppe: 2–3 elever
  • Kode: blokk eller Python

Læringsmål

  1. Bruke micro:bitens sensorer til å måle temperatur, lys og bevegelse
  2. Programmere i blokk eller Python (MicroPython)
  3. Koble målingene til naturfagbegreper (energi, klima, kraft/bevegelse)
  4. Bruke radio til å sende måledata mellom micro:bitter

Micro:bit har innebygde sensorer. I naturfag bruker vi dem som måleinstrumenter.

Aktivitet A – Temperatur og mikroklima (25 min)

Naturfag

Temperatur er et mål på den gjennomsnittlige kinetiske energien til partikler. Ute og inne, i sol og skygge, blir det ulike mikroklima. Små forskjeller (1–3 °C) kan bety mye for planter, dyr og energibruk i bygg.

Oppgave

  1. Programmer micro:bit til å vise temperatur når du trykker A.
  2. Mål på tre steder (f.eks. ved vindu, midt i rommet, under bord).
  3. Noter resultatene i tabellen.
  4. Utfordring: Glad ansikt hvis 18–22 °C, ellers trist (komfortsone).

Python (MicroPython)

from microbit import *

while True:
    if button_a.was_pressed():
        temp = temperature()
        display.scroll(str(temp))

        # Utfordring: komfortsone 18–22 °C
        if 18 <= temp <= 22:
            display.show(Image.HAPPY)
        else:
            display.show(Image.SAD)
Spørsmål til naturfag
  1. Hvilket sted var varmest, og hvorfor?
  2. Er micro:bit-temperaturen nøyaktig nok til vitenskapelige forsøk? Hva kan påvirke målingen?

Aktivitet B – Lys og energi (25 min)

Naturfag

Lys er elektromagnetisk stråling. Planter bruker synlig lys til fotosyntese. Lysstyrken påvirker også energibruk til belysning. Micro:bit måler en relativ lysverdi (0–255) – nyttig til å sammenligne.

Oppgave

  1. Vis lysnivå når du trykker B.
  2. Mål ved vindu, midt i rommet og under bord.
  3. Lag energi-indikator: lavt → L, middels → M, sterkt → H.
  4. Utfordring: Send lysverdien med radio til partnerens micro:bit.

Python

from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    if button_b.was_pressed():
        lys = display.read_light_level()
        display.scroll(str(lys))

        if lys < 50:
            display.show("L")
        elif lys < 150:
            display.show("M")
        else:
            display.show("H")

        radio.send(str(lys))

    mottatt = radio.receive()
    if mottatt:
        display.scroll(mottatt)
Spørsmål til naturfag
  1. Hvorfor er det lyst ved vinduet, men mørkere lenger inn?
  2. Hvordan henger lys og energi sammen i et klasserom (vindu vs. elektrisk lys)?

Aktivitet C – Bevegelsesalarm med radio (20 min)

Naturfag + radio

Akselerometeret registrerer endring i fart. Når micro:bit ristes, endres akselerasjonen. Kobling til kraft og bevegelse: en kraft gir akselerasjon.

Oppgave – «Bevegelsesalarm»

  • Micro:bit 1 (sensor): Oppdager rist og sender radio-melding.
  • Micro:bit 2 (mottaker): Viser alarm når melding mottas.

Bruk samme radiogruppe (f.eks. 7), eller gruppenummeret deres hvis mange jobber samtidig.

Blokk – sensor (sender)

ved start
    → radio sett gruppe 7

når ristet
    → radio send streng "ALARM"
    → vis ikon (kryss)

Blokk – mottaker

ved start
    → radio sett gruppe 7

på radio mottatt streng
    → hvis mottatt streng = "ALARM" da
          vis ikon (ja)

Python – sensor

from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    if accelerometer.was_gesture("shake"):
        radio.send("ALARM")
        display.show(Image.NO)
        sleep(500)
        display.clear()

Python – mottaker

from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    msg = radio.receive()
    if msg == "ALARM":
        display.show(Image.YES)
        try:
            import music
            music.play(music.BA_DING)
        except ImportError:
            pass
        sleep(1000)
        display.clear()
Spørsmål til naturfag
  1. Hva må til for at akselerometeret skal «reagere»?
  2. Nevn én reell situasjon der bevegelsessensor + trådløs varsling er nyttig.
