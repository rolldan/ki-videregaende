Micro:bit i naturfag

Oppgavetekst, instruks og kode til hele økten. Bruk MakeCode (blokk) – Python ligger som alternativ.

Navn: Gruppe nr.:          Radiogruppe:
MakeCode Python Editor

Dette skal du ha

  • Minst 2 micro:bitter
  • USB-kabel eller batteripakke til hver
  • PC med nettleser

Slik laster du ned program

  1. Åpne makecode.microbit.org
  2. Velg Nytt prosjekt
  3. Bygg med blokker (eller bytt til Python)
  4. Trykk Last ned og dra .hex-fila til micro:bit
  5. Radio må testes på fysiske micro:bitter

Oppgave 1 – Bli kjent med MakeCode (15 min)

Oppgavetekst

Bli kjent med Microsoft MakeCode. Finn fram i editoren, test simulatoren og last ned et program til micro:bit.

Instruks

  1. Gå til MakeCode og lag et nytt prosjekt (f.eks. Oppgave1).
  2. Finn menyene Grunnleggende, Inndata og Radio.
  3. Se på simulatoren i midten.
  4. Last ned et enkelt program til micro:biten.

  • Jeg har testet noe i simulatoren
  • Jeg har lastet ned program til micro:bit

Oppgave 2 – Tekst og symbol (15 min)

Oppgavetekst

Få micro:bit til å vise en tekst og deretter et symbol når den starter.

Instruks

  1. Bruk blokken ved start.
  2. Legg inn vis streng med en tekst du velger.
  3. Legg inn en kort pause.
  4. Legg inn vis ikon (eller tegn eget med vis lysdioder).
  5. Last ned og test.

Kode

Blokk

ved start
    → vis streng "Hei"
    → pause (ms) 1000
    → vis ikon (hjerte)

Python

from microbit import *

display.scroll("Hei")
sleep(1000)
display.show(Image.HEART)
Naturfag: LED-skjermen gjør elektrisk energi om til lysenergi.

Oppgave 3 – Utforsk knapp A og B (15 min)

Oppgavetekst

Programmer knappene slik at A og B gjør ulike ting.
HandlingSkal skje
Trykk AVis tekst «A» (eller et tall)
Trykk BVis et symbol (f.eks. smilefjes)
Trykk A+B (valgfritt)Tøm skjermen

Instruks

  1. Finn blokkene under Inndata: når knapp A trykkes / når knapp B trykkes.
  2. Koble tekst til A og ikon til B.
  3. (Valgfritt) Legg til A+B → tøm skjerm.
  4. Last ned og test.

Kode

Blokk

når knapp A trykkes
    → vis streng "A"

når knapp B trykkes
    → vis ikon (glad)

når knapper A+B trykkes
    → tøm skjerm

Python

from microbit import *

while True:
    if button_a.was_pressed():
        display.scroll("A")
    if button_b.was_pressed():
        display.show(Image.HAPPY)
    if button_a.is_pressed() and button_b.is_pressed():
        display.clear()

Oppgave 4 – Giver og mottaker (25 min)

Oppgavetekst

Lag to roller: giver (sender) og mottaker. Send en beskjed mellom to micro:bitter. Deretter skal dere kunne sende meldinger begge veier.

Viktig: Begge må ha samme radiogruppe. Skriv den øverst på arket.

Instruks – del A (én vei)

  1. Avtal radiogruppe i gruppa.
  2. Last giver-programmet på micro:bit 1.
  3. Last mottaker-programmet på micro:bit 2.
  4. Trykk A på giveren. Mottakeren skal vise «HEI».

Kode – del A

Giver (blokk)

ved start
    → radio sett gruppe 3

når knapp A trykkes
    → radio send streng "HEI"
    → vis ikon (ja)

Mottaker (blokk)

ved start
    → radio sett gruppe 3

på radio mottatt streng
    → vis streng (mottatt streng)

Giver (Python)

from microbit import *
import radio

radio.on()
radio.config(group=3)

while True:
    if button_a.was_pressed():
        radio.send("HEI")
        display.show(Image.YES)
        sleep(400)
        display.clear()

Mottaker (Python)

from microbit import *
import radio

radio.on()
radio.config(group=3)

while True:
    msg = radio.receive()
    if msg:
        display.scroll(msg)

Instruks – del B (begge veier)

  1. Last samme program på begge micro:bitene.
  2. A sender «HEI», B sender «OK».
  3. Test at dere kan sende beskjed til hverandre.

Kode – del B

Toveis (blokk, samme på begge)

ved start
    → radio sett gruppe 3

når knapp A trykkes
    → radio send streng "HEI"

når knapp B trykkes
    → radio send streng "OK"

på radio mottatt streng
    → vis streng (mottatt streng)

Toveis (Python, samme på begge)

from microbit import *
import radio

radio.on()
radio.config(group=3)

while True:
    if button_a.was_pressed():
        radio.send("HEI")
    if button_b.was_pressed():
        radio.send("OK")

    msg = radio.receive()
    if msg:
        display.scroll(msg)
Naturfag: Radioen bruker elektromagnetiske bølger (ca. 2,4 GHz) – samme type som Wi‑Fi og Bluetooth.

Oppgave 5 – Signalstyrke (20 min)

Oppgavetekst

Undersøk hva som påvirker radio-signalet. Én micro:bit er giver, én er mottaker. Mottakeren viser signalstyrke. Endre én ting om gangen og noter resultatene.

Signalstyrke er ofte negative tall (f.eks. −42). Nærmere null = sterkere signal (−30 er sterkere enn −80).

Instruks

  1. Last giver- og mottaker-programmet (bruk MakeCode-blokk for signalstyrke).
  2. Sett sendeeffekt til 6 først.
  3. Gjennomfør testene i tabellen. Endre bare én ting per test.
  4. Svar på spørsmålene.

Kode

Giver (blokk)

ved start
    → radio sett gruppe 3
    → radio sett sendeeffekt 6

når knapp A trykkes
    → radio send streng "PING"
    → vis ikon (diamant)

Mottaker (blokk)

ved start
    → radio sett gruppe 3

på radio mottatt streng
    → vis tall (radio signalstyrke)

Finn «radio signalstyrke» under Radio → mer / avansert.

Giver (Python)

from microbit import *
import radio

radio.on()
radio.config(group=3, power=6)

while True:
    if button_a.was_pressed():
        radio.send("PING")
        display.show(Image.DIAMOND)
        sleep(300)
        display.clear()
