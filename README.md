# KI i alle fag – Videregående

Implementeringsplan og nettside for trygg, skapende og kritisk bruk av kunstig intelligens på videregående skole i Akershus fylkeskommune.

## Nettside

Nettsiden er publisert via GitHub Pages:

**https://rolldan.github.io/ki-videregaende/**

## Innhold

- Tre komplementære spor: felleskurs, fagteam og enkeltlærerveiledning
- Implementeringsfaser 2025–2028
- KI-modenhetsmatrise for vurdering
- Fagspesifikke hensyn og roller
