Elevhefte · Micro:bit + naturfag

Sensorer, signaler og undersøkelser

To økter à 90 minutter der du programmerer micro:bit for å måle, sende og tolke naturfaglige data. Dere har allerede jobbet med trådløs kommunikasjon – nå bygger vi videre med sensorer og en egen undersøkelse.

Påbygg · Naturfag (NAT01‑05) 2 × 90 min MakeCode: blokker + Python Pararbeid anbefales

Hva skal du lære?

Arbeidet er knyttet til kompetansemål i naturfag for vg3 påbygging:

  • vurdere og lage programmer som modellerer naturfaglige fenomener
  • forklare hovedprinsippene for trådløs kommunikasjon og gi eksempler på bruk
  • utforske og beskrive elektromagnetisk stråling og sentrale bølgefenomener
  • bruke naturvitenskapelig metode: hypotese, måling, feilkilder og konklusjon
Før dere starter: Åpne makecode.microbit.org. Du kan bytte mellom Blokker og Python i menyen. Last ned programmet til micro:bit via USB.

Utstyr per gruppe

Teknisk

  • 2 micro:bit (helst V2) + batteripakker
  • 2 USB-kabler og 1 PC/Chromebook
  • Valgfritt: papir, tape, aluminiumsfolie, stoff, plastboks

Dere kan allerede

  • Sende og motta meldinger med radio
  • Bruke knapper og LED-skjermen
  • Bygge enkle løkker og vilkår

Økt 1 · Temperatur, isolasjon og trådløs sensor (90 min)

Naturfaglig tema: varme, energi og miljø. Dere måler temperatur, sender data trådløst og undersøker hvilket materiale som isolerer best.

0–10 min · Oppstart

Kort repetisjon av radio. Diskuter: Hvorfor er isolasjon viktig for energibruk og klima?

10–30 min · Oppgave A

Programmer temperatursensor og les av verdier.

30–55 min · Oppgave B

Lag trådløs værstasjon: én sender, én mottaker.

55–85 min · Oppgave C

Isolasjonsforsøk med hypotese, målinger og feilkilder.

85–90 min · Oppsummering

Del ett funn med klassen. Lagre koden.

Oppgave A – Les temperatur (15–20 min)

Micro:bit har en innebygd temperatursensor (måler chip-temperaturen – omtrent romtemperatur, men påvirkes litt av at kortet blir varmt).

Mål: Vis temperaturen på skjermen hvert sekund. Trykk A for å «fryse» verdien.

Blokker
  1. Fra Grunnleggende: sett inn vis tall.
  2. Fra Inndata: dra temperatur (°C) inn i vis tall.
  3. Pakke dette inn i gjenta for alltid og legg til pause (ms) 1000.
  4. Fra Inndata → ved knapp A trykket: vis tall (temperatur) og pause 2000.
Python
from microbit import *

while True:
    temp = temperature()
    if button_a.was_pressed():
        display.show(str(temp))
        sleep(2000)
    else:
        display.scroll(str(temp))
        sleep(500)
Sjekk: Er målingen nær termometer/romtemperatur? Hvorfor kan micro:bit vise litt høyere verdi etter en stund?

Oppgave B – Trådløs temperaturstasjon (20–25 min)

Bruk det dere kan om radio. Én micro:bit er sensor (ute / i forsøket), den andre er display (hos dere).

Krav: Sensor sender temperatur hvert 2. sekund. Mottaker viser verdien. Bruk samme radiogruppe (f.eks. 7).

Sensor (sender)

Blokker
  1. ved start → radio sett gruppe 7.
  2. gjenta for alltid:
    • radio send tall (temperatur)
    • vis ikon (ja) kort, så pause 2000
Python
from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    t = temperature()
    radio.send(str(t))
    display.show(Image.YES)
    sleep(200)
    display.clear()
    sleep(1800)

Mottaker (display)

Blokker
  1. ved start → radio sett gruppe 7.
  2. ved radio mottatt tall → vis tall (mottatt tall).
Python
from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    melding = radio.receive()
    if melding:
        display.scroll(melding)
Naturfagkobling: Trådløs kommunikasjon bruker radiobølger (elektromagnetisk stråling). Signalet dempes av avstand og materialer – det bruker dere aktivt i økt 2.

Oppgave C – Isolasjonsforsøk (30 min)

Problemstilling: Hvilket materiale holder best på varmen?

  1. Lag en hypotese (f.eks. «ull isolerer bedre enn plast»).
  2. Varm hendene / bruk en flaske med varmt vann som «varmekilde» nær sensor-micro:bit.
  3. Pakk sensoren inn i ulike materialer (folie, stoff, papir, luft/ingen pakking).
  4. Mål temperatur hvert 30. sekund i 3–4 minutter per materiale. Noter i tabellen.
  5. Diskuter feilkilder: starttemperatur, hvor tett pakket, egenvarme fra chip, tid.

Økt 2 · Radiobølger, demping og egen undersøkelse (90 min)

Naturfaglig tema: bølger, elektromagnetisk stråling og trådløs teknologi. Dere måler hvordan signalet påvirkes, og gjennomfører en egen undersøkelse.

0–15 min · Teori + Oppgave D

Radiobølger, frekvens og demping. Test signalstyrke.

15–35 min · Oppgave E

Programmer signalstyrke-måler og undersøk materialer/avstand.

35–75 min · Oppgave F

Egen undersøkelse (velg én problemstilling).

75–90 min · Presentasjon

2 minutter per gruppe: problemstilling, metode, funn, feilkilder.

Kort teori – husk dette

Radiobølger

Micro:bit radio bruker 2,4 GHz – samme område som Wi‑Fi og Bluetooth. Det er elektromagnetisk stråling med lav energi (ikke ioniserende).

Demping

Signalet svekkes med avstand og når det går gjennom materialer (spesielt metall og vann). Det ligner hvordan lys dempes gjennom tette stoffer.

Oppgave D – Signalstyrke (RSS)

Når mottakeren får en radiomelding, kan den også lese signalstyrke (RSS = Received Signal Strength). Jo nærmere 0, desto sterkere signal (verdier er negative, f.eks. −40 er sterkere enn −80).

Sender (enkel «ping»)

Blokker
  1. ved start: radio sett gruppe 7.
  2. gjenta for alltid: radio send streng "ping" + pause 500.
Python
from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    radio.send("ping")
    display.show(".")
    sleep(500)

Mottaker (vis signalstyrke)

Blokker
  1. ved start: radio sett gruppe 7.
  2. ved radio mottatt pakke:
    • vis tall (radio signalstyrke)

Tips: I MakeCode finner du signalstyrke under Radio → mer …

Python
from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    detaljer = radio.receive_full()
    if detaljer:
        melding, signalstyrke, tidspunkt = detaljer
        # signalstyrke: typisk ca. -30 (sterk) til -90 (svak)
        display.scroll(str(signalstyrke))

Oppgave F – Egen undersøkelse (velg én)

Velg problemstilling, lag hypotese, programmer, mål, og forklar resultatet med naturfag.

1. Klima i klasserommet

Hvordan endres temperatur og lys gjennom økta? Logg verdier hvert minutt og lag en enkel modell/graf.

2. Isolasjon 2.0

Hvilken «vegg» (sjikt) holder best på varmen? Sammenlign med virkelige hus og energisparing.

3. Radiodekning

Hvor langt når signalet i skolebygget? Kartlegg blinde soner og forklar med demping/refleksjon.

4. Lys og skygge

Bruk lyssensoren. Hvordan endres lysnivå ved vindu vs. inne i rommet? Knytt til energi fra sola.

Ekstra kode: temperatur + lys i én melding

Python
from microbit import *
import radio

radio.on()
radio.config(group=7)

while True:
    data = "T:{} L:{}".format(temperature(), light_level())
    radio.send(data)
    display.scroll(data, delay=80)
    sleep(2000)
Blokker – mottaker
  1. ved radio mottatt streng → vis streng (mottatt streng).
  2. Valgfritt: lagre verdier på papir hvert minutt til graf.

Blokker
  1. gjenta for alltid → vis tall (lysnivå) → pause 1000.

Alarm når det blir for varmt

Python
from microbit import *

GRENSE = 28  # juster selv

while True:
    t = temperature()
    if t >= GRENSE:
        display.show(Image.ANGRY)
        # micro:bit V2:
        try:
            import music
            music.pitch(880, 200)
        except ImportError:
            pass
    else:
        display.show(Image.HAPPY)
    sleep(500)

Enkel «modell» – beregnet følt temperatur

En modell forenkler virkeligheten. Her er en leken modell: «følt temperatur» = temperatur − (hvor mørkt det er) / 50. Diskuter: Er dette en god modell? Hva mangler? 

from microbit import *

while True:
    t = temperature()
    lys = light_level()
    folt = t - (255 - lys) / 50
    display.scroll("{:.1f}".format(folt))
    sleep(1500)
