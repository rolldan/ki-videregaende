Algoritmer og Python-lab i 2P-Y

I 2P-Y bruker vi Python når regnestykkene gjentas mange ganger (sparing måned for måned), når vi analyserer datasett i lister, eller når vi skal finne skjæringspunkter og nullpunkter med halveringsmetoden. Alt kjører direkte her i nettleseren uten installasjon.

1De fem Python-byggesteinene i 2P-Y

Huskelapp for Python-operatorer i matematikk
  • Potens ($a^n$): Skrives med to stjerner a ** n (ikke ^!). For eksempel er $1{,}05^{10}$ lik 1.05 ** 10.
  • Desimaltall: Python bruker alltid punktum: 0.85 (komma lager liste/tuppel).
  • while-løkke: Gjentar så lenge en betingelse er sann – perfekt når vi spør «hvor mange måneder tar det før kontoen passerer 100 000 kr?».
  • for-løkke og lister: Går gjennom faste år range(1, 11) eller målinger i ei liste lonn = [310, 460, 480, ...].
  • Funksjoner def f(x): Lar oss definere matematiske modeller som $f(x)$ og kalle dem mange ganger.

4Egenvurderingsoppgaver i Python og algoritmer

Oppgave 5.1 · Del 1: Hva skriver programmet ut? Ikke løst ennå

Les koden under uten å kjøre den først. Hvilket tall skrives ut til slutt?

belop = 10000
aar = 0
while belop < 20000:
    belop = belop * 1.20
    aar = aar + 1
print(aar)
Hint: Å gange med $1{,}20$ betyr $+20\,\%$ for hver runde. Regn ut runde 1, 2, 3 og 4.
Løsning: Start: belop = 10 000, aar = 0.
• Runde 1: $10\,000 \cdot 1{,}2 = 12\,000$, aar = 1
• Runde 2: $12\,000 \cdot 1{,}2 = 14\,400$, aar = 2
• Runde 3: $14\,400 \cdot 1{,}2 = 17\,280$, aar = 3
• Runde 4: $17\,280 \cdot 1{,}2 = 20\,736 \ge 20\,000$, aar = 4. Løkka avsluttes og skriver ut 4.
